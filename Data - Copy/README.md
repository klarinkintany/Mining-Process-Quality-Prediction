# Dataset Documentation

## Project
Mining Process Quality Prediction

## Dataset Source
The dataset used in this project is the *Quality Prediction in a Mining Process* dataset, originally published on Kaggle.
Link : https://www.kaggle.com/code/korrapatyairit/ml-regression-quality-prediction-in-a-mining-proc/input

## Dataset Description
The dataset contains industrial process measurements from an iron ore flotation plant. It includes process variables and product quality measurements collected over time.

## Data Processing
The original dataset was cleaned before analysis:
- Original records: 737,453
- Duplicate records removed: 1,171
- Final cleaned records: 736,282
- Number of columns: 24
- Missing values after cleaning: 0
